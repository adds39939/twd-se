# Developer notes

Everything here was worked out while building the editor: by reading the game's own data and scripts, by decompiling parts of the engine, and by putting edited saves in front of the game. Start with the save formats, then the season you care about.

| File | What it covers |
|------|----------------|
| [save-formats.md](save-formats.md) | MetaStream, property sets, bundles, event logs, how names become hashes |
| [engine.md](engine.md) | What the engine does when it loads a save, the developer chapter menus, and what a hand-made checkpoint must contain |
| [season-1.md](season-1.md) | Season 1 and 400 Days: persistent decisions, the autosave, chapter checkpoints, items |
| [season-2.md](season-2.md) | Season 2: the event log, decisions as dialog nodes, chapter checkpoints, items |
| [season-3.md](season-3.md) | A New Frontier: story keys, the imported Season 2 block, skipped episodes, items |
| [michonne.md](michonne.md) | Michonne: where it differs from Season 3 |
| [season-4.md](season-4.md) | The Final Season: two imported blocks, the story builder, loaded scenes, collectibles |
| [architecture.md](architecture.md) | How the solution is laid out, the season handler contract, adding a season, the test projects |
| [tools.md](tools.md) | The console tools in `tools/`, what they read and what they write |
| [decompiling.md](decompiling.md) | Getting the game's scripts and data out of its archives, decompiling Lua with unluac in Docker, and decompiling the engine |
| [testing-in-game.md](testing-in-game.md) | How edited saves were checked against the real game |

Season-specific data the app ships (decision lists, chapter lists, item lists) lives in each season project's `Data/` folder and is generated by the tools; the docs say which tool writes which file.
